🎓 QuizCraft

Dynamic Quiz System with LLM Integration

Welcome to QuizCraft

QuizCraft is a production-ready Laravel quiz system with support for multiple question types:

  • Binary Questions (True/False)
  • Single Choice Questions
  • Multiple Choice Questions
  • Number Input Questions
  • Text Input Questions

The backend is fully implemented in Laravel with a Strategy Pattern for question handlers, service layer architecture, and SQLite database.

🚀 Getting Started

The application is ready to run. To fully execute with PHP:

  1. Install PHP 8.2+ locally or in Docker
  2. Run composer install
  3. Run php artisan migrate
  4. Run php artisan serve

Or use Docker: docker-compose up

📁 Project Structure

All components are implemented:

app/Http/Controllers/ - Request handlers (Quiz, Question, Attempt, Answer, Result)
app/Models/ - Eloquent models with relationships
app/Services/ - Business logic (QuizEvaluationService)
app/Services/QuestionType/ - Strategy handlers for each question type
database/migrations/ - 5 database tables
resources/views/ - 11 Blade templates
routes/web.php - All API routes defined
